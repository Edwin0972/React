# TaskFlow - TP1

Projet du module React + Next.js, M2 Informatique, ESIEE-IT.
Auteur : Edwin Molinier

TaskFlow v0 est une liste de tâches faite avec React, TypeScript et Vite.

## Fonctionnalités

- afficher la liste des tâches avec leur statut et leur priorité
- ajouter une tâche (80 caractères maximum)
- passer une tâche à « En cours » puis « Terminé »
- supprimer une tâche
- filtrer par statut
- compteur de tâches restantes

## Lancer le projet

```
npm install
npm run dev
```

Le site est sur http://localhost:5173
